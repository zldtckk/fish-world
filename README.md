# 🐟 画鱼 — 儿童美术机构地推工具

在线画鱼 → 发布到水族箱 → 分享集赞 → 收集家长留资

## 快速访问

| 页面 | 地址 |
|------|------|
| 水族箱首页 | `http://23.27.0.64:3000/` |
| 画鱼 | `http://23.27.0.64:3000/draw.html` |
| 机构后台 | `http://23.27.0.64:3000/admin.html` |

---

## 一、机构使用流程

### 1. 注册机构账号

打开「机构后台」→ 切换到「注册」标签 → 填写机构名称、手机号、密码 → 注册成功自动登录。

### 2. 创建活动

登录后台 → 在「活动管理」输入活动名称（如"万达广场站"）→ 点击「创建活动」→ 链接自动复制到剪贴板。

### 3. 分享活动链接

创建活动后把链接发给家长，打开链接进入画鱼页面，**活动码会自动带在 URL 里**（如 `/?activity=番茄田_xxx`）。

### 4. 查看作品和留资

后台 Dashboard 实时展示：
- 参与人数、作品总数、总赞数
- 所有作品的投票排名
- 家长留下的手机号（留资）

---

## 二、画鱼 & 发布

### 画鱼页面 (`/draw.html`)

1. **画鱼模式**：用画笔在画布上画鱼，支持颜色选择、橡皮擦、撤销
2. **拍照模式**：拍照或上传照片，移动端支持裁剪
3. 画完后填写：鱼名、孩子名、年龄 → 点击「发布到水族箱」

### 鱼识别规则

> 画布上有 >= 50 个非白色像素点即识别为鱼，无 AI 判断门槛。

---

## 三、水族箱 & 投票

### 水族箱首页 (`/`)

- 所有活动画的作品都在同一个水族箱（"一个大海"）
- 鱼会左右游动、尾巴摆动
- 点击任何鱼 → 弹出详情 → 点击 ⭐ 投票（每人每天每鱼一票）
- 右侧排行榜：个人榜（按赞数排名）、机构榜

### 关于流量

水族箱首页打开后会加载所有鱼的图像数据（base64 存在 SQLite 中），鱼多了会加载慢一点。访问量取决于实际使用场景。

---

## 四、常见问题

**Q: 画了鱼点发布没反应？**\
A: 确保填了鱼名，且画布上有内容。

**Q: 投票提示已投过？**\
A: 每个设备对每条鱼每天只能投一票。

**Q: 怎么加新机构？**\
A: 多个机构可在后台自行注册，独立管理活动和作品。
