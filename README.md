# 🐟 大家一起来画鱼

在线画鱼 → 发布到水族箱 → 分享集赞 → 收集家长留资

> 儿童美术机构地推引流工具，零门槛画鱼，分享裂变获客。

---

## 📱 使用指南

### 🎨 画鱼（面向孩子）

1. 打开「画鱼」页面，在画布上画一条鱼
2. 选颜色、调笔刷大小、画错了可以用橡皮擦或撤销
3. 画完后填写：**鱼的名字、孩子的名字、年龄**
4. 点击「发布到水族箱」— 鱼就会出现在水族箱里游动

> 画布上有内容即可发布，没有复杂的 AI 识别门槛。

### 🌊 水族箱（面向所有人）

水族箱展示所有孩子画的鱼：

- **点击鱼** → 查看详情、点赞
- **双击鱼** → 撒饲料（鱼会游过来吃）
- **🫘 喂食按钮** → 随机位置撒饲料
- **⛶ 全屏按钮** → 进入沉浸式观赏模式

**全屏模式：**
- 手机横屏：全屏自动旋转 90°，鱼游满整个屏幕
- 手机竖屏：全屏填满竖屏，不旋转（微信内也支持）
- 桌面端：全屏铺满显示器
- 点「✕ 退出全屏」或按 ESC 退出

**个人鱼高亮：** 你自己画的鱼会有 ✨ 光效，方便在水族箱里找到。

### ⭐ 点赞

- 每条鱼每天每设备可投一票
- 点赞后不能取消
- 点赞数影响排行榜排名

### 🏆 排行榜

- **个人榜**：按点赞数排名，前三名 🥇🥈🥉
- **机构榜**：按机构总赞数排名
- 自己的鱼在排行榜顶部高亮显示

### 📤 分享

- 在排行榜点击「分享」按钮，复制链接发给朋友
- 朋友打开链接可以直接看到你的鱼并点赞

## 🏫 机构使用流程

### 1. 注册机构账号

打开「机构后台」→ 切换到「注册」标签 → 填写机构名称、手机号、密码 → 注册成功自动登录。

### 2. 创建活动

登录后台 → 在「活动管理」输入活动名称（如"万达广场站"）→ 点击「创建活动」→ 链接自动复制到剪贴板。

### 3. 分享活动链接

创建活动后把链接发给家长，打开链接进入画鱼页面，**活动码会自动带在 URL 里**（如 `/?activity=番茄田_xxx`）。

### 4. 查看作品和留资

后台 Dashboard 实时展示：
- 参与人数、作品总数、总赞数
- 所有作品的投票排名
- 家长留下的手机号（留资）

## ⚙️ 常见问题

**Q: 画了鱼点发布没反应？**
A: 确保填了鱼名，且画布上有内容。

**Q: 投票提示已投过？**
A: 每个设备对每条鱼每天只能投一票。

**Q: 怎么加新机构？**
A: 多个机构可在后台自行注册，独立管理活动和作品。

**Q: 手机全屏退不出？**
A: 点击右上角「✕ 退出全屏」按钮，或按手机返回键。

**Q: 在微信里打开能用吗？**
A: 完全兼容微信内置浏览器，所有功能正常使用。
